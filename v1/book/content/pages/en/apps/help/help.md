# Help

The Help app provides quick access to official Hubleto resources. Instead of searching for the correct website manually, you can open the appropriate documentation or support page directly from your Hubleto workspace.

The available links cover both everyday use and technical development. Each resource opens in a new browser tab, allowing you to keep your current Hubleto page open while you read the documentation or prepare an issue report.

## Available resources

### User guide

Open the user guide when you need an explanation of a Hubleto feature or instructions for completing a task. The guide covers general navigation and behavior as well as individual applications. It should normally be your first destination when you are unsure how something is intended to work.

### GitHub issue tracker

Use the GitHub issue tracker when you believe you have found a software bug. Before creating a new issue, search the existing reports to see whether the same behavior has already been documented. When reporting a new problem, describe what you expected, what happened instead, and the steps needed to reproduce it. Relevant version information can be found in the **About** app.

### Developer guide

The developer guide contains technical documentation for building, extending, and integrating Hubleto. It is intended for developers and implementation specialists who work with the framework, application structure, or custom functionality.

### Hubleto website

The Hubleto website provides general information about the platform and the wider project. Use it to learn more about Hubleto outside the context of a specific feature or technical issue.

## Before reporting a problem

First check the user guide and search the existing GitHub issues. If the problem has not already been explained or reported, collect a concise description, the steps that reproduce it, and any relevant environment information from the About page. Providing this context helps maintainers understand and investigate the issue more efficiently.
