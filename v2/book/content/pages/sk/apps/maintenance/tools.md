# Nástroje

Sekcia Nástroje zhromažďuje technické pomôcky pre administrátorov a vývojárov s príslušnými oprávneniami. Dostupné položky závisia od nainštalovaných aplikácií.

## Technické nástroje

* **Vývojárske nástroje:** Môžu obsahovať návrhár formulárov a kontrolu konzistencie databázy. Nejde o všeobecnú konzolu na spúšťanie ľubovoľných SQL príkazov alebo skriptov.
* **Prehliadač logov:** Zobrazuje dostupné serverové log súbory. Neposkytuje samostatný živý monitoring výkonu ani univerzálny audit API požiadaviek.

Technické údaje môžu byť citlivé. Prístup k nim má byť obmedzený na používateľov, ktorí ich potrebujú na správu alebo vývoj.
